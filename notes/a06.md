# A06：多文件 Makefile

## 三个概念
- 目标：要得到的文件
- 依赖：构建目标时需要的文件
- recipe：执行的具体命令

## 实验
- 首次 make 执行了什么：完全构建
- 第二次 make 为什么没有重建：all 目标已经是最新的，没有任何依赖发生变化
- 修改一个 .c 后重建了什么：该 .c 文件及其依赖的 .h 文件
- 修改公共 .h 后重建了什么：所有包含该 .h 文件的 .c 文件
- make clean 后再 make 发生了什么：完全构建

## 我的理解
- -Iinclude 和头文件依赖有什么区别？
    - -I include 是把include目录作为头文件查找目录，头文件依赖是指定目标文件的依赖关系，告诉 make 在构建目标文件时需要哪些头文件。
- GCC 和 make 分别负责什么？
    - GCC 负责编译源代码文件，生成目标文件或可执行文件。make 负责管理构建过程，决定哪些文件需要重新编译，并调用 GCC 执行编译命令。
