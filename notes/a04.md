# 指令
- chmod u-x file：去掉文件的用户可执行权限
- chmod u+x file：增加文件的用户可执行权限
- export PATH=$PATH:/home/username/bin：将 /home/username/bin 添加到 PATH 环境变量中
- ps -ef 查看所有进程信息

| 列 | 含义 |
|---|---|
| `UID` | 进程所属用户 |
| `PID` | 进程 ID |
| `PPID` | 父进程 ID |
| `CMD` | 命令及参数 |

- kill PID: 默认 kill 发送 SIGTERM，表示请求目标进程终止。它不是直接“删除进程”，程序可以处理或忽略这个信号
