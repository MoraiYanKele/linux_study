# 理解程序的三个标准流

| 名称 | 编号 | 用途 | 默认连接 |
|---|---:|---|---|
| stdin（标准输入） | 0 | 接收输入 | 终端键盘 |
| stdout（标准输出） | 1 | 输出正常结果 | 终端屏幕 |
| stderr（标准错误） | 2 | 输出错误或诊断信息 | 终端屏幕 |


# > & >> 
| 写法 | 含义 |
|---|---|
| `> file` | 把 stdout 写入文件，覆盖原内容 |
| `>> file` | 把 stdout 追加到文件末尾 |
| `2> file` | 把 stderr 写入文件，覆盖原内容 |
| `2>> file` | 把 stderr 追加到文件末尾 |

echo ：将字符串输出到 stdout

echo '$HOME'
echo "$HOME"

单引号：保留原文字，输出 $HOME。
双引号：允许变量展开，输出你的家目录。

# $?
表示上一条指令的退出状态 0表示正确返回， 非0表示有问题状况

# 整理产出

| 项目 | stdout | stderr | 退出状态 |
|---|---|---|---|
| 传递什么 | 正常结果文本 | 错误或诊断文本 | 程序结束结果 |
| 如何产生 | `puts(...)` 等 | `fprintf(stderr, ...)` 等 | `return 0`、`return 7` 等 |
| 如何接收 | `>`、`>>`、普通管道 | `2>`、`2>>` | 立即读取 `$?` |
| `./demo` | INFO 信息 | ERROR 信息 | `0` |
| `./demo fail` | INFO 信息 | ERROR 信息 | `7` |
